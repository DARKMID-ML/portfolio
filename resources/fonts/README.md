# Polices auto-hébergées

Les fichiers WOFF2 de ce dossier proviennent de
[Google Fonts](https://fonts.google.com) et de
[Bunny Fonts](https://fonts.bunny.net) et sont distribués sous licence
SIL Open Font License 1.1 :

- **Anybody** — variable, graisse 800, axes `wdth` 75–125 (identité publique)
- **Bricolage Grotesque** — 400, 500, 600, 700, 800 (interface et secours)
- **Instrument Sans** — 400, 500, 600 (texte courant)
- **DM Mono** — 400, 500 (libellés techniques)

Les fichiers **Instrument Serif** restent présents pour référence historique
mais ne sont plus chargés par l'application depuis la direction « MID / 223 ».

Seul le format WOFF2 est conservé : il est pris en charge par tous les
navigateurs modernes et évite d'embarquer des variantes WOFF redondantes.
